# Acceleration-and-velocity
The acceleration of an object is the derivative of the velocity with respect to time. So, integrating an acceleration function can give you the velocity of the object.
An object has an acceleration that is described by the equation:
𝑎𝑎(𝑡𝑡) = 7𝑡 sin 5𝑡 m/s2
Given that its initial velocity was zero, plot the velocity as a function of time from t=0 to t=10 seconds.
To do this, use a for loop with t values ranging from 0 to 10 with an increment of 0.02.
In each iteration of the loop, determine the velocity. Save this into a velocity array.
Once the loop is complete, plot velocity vs. time. (Add a title and axis labels.)
